## 🚀 نحوه نصب و راه‌اندازی

### مرحله 1: نصب وب سرویس پایتون

1. پایتون نسخه 3.8 یا بالاتر را نصب کنید
2. کتابخانه‌های مورد نیاز را نصب کنید:

```bash
pip install flask flask-cors ancientlinesoftheworld
```

فایل api.py را دانلود کرده و اجرا کنید:
```
python api.py
```





## وب سرویس روی آدرس http://localhost:5001 اجرا می‌شود
توجه مهم: وب سرویس باید همیشه در حال اجرا باشد تا افزونه وردپرس بتواند با آن ارتباط برقرار کند
##نصب افزونه و قالب در وردپرس

روش اول: نصب از طریق ادمین وردپرس (پیشنهادی)
وارد ادمین وردپرس شوید (http://your-site.com/wp-admin)

برای افزونه: به بخش افزونه‌ها → افزودن جدید → آپلود افزونه بروید

فایل ancient-lines-plugin.zip را انتخاب کرده و روی نصب کلیک کنید

پس از نصب، روی فعال‌سازی کلیک کنید

برای قالب: به بخش نمایش → قالب‌ها → افزودن جدید → آپلود قالب بروید

فایل ancient-lines-theme.zip را انتخاب کرده و روی نصب کلیک کنید

پس از نصب، روی فعال‌سازی کلیک کنید

روش دوم: نصب دستی (از طریق FTP)
فایل‌های zip را در کامپیوتر خود اکسترکت کنید

پوشه ancient-lines-plugin را به wp-content/plugins/ آپلود کنید

پوشه ancient-lines-theme را به wp-content/themes/ آپلود کنید

در ادمین وردپرس، افزونه و قالب را فعال کنید
مرحله 3: تنظیمات نهایی
در ادمین وردپرس، به بخش Ancient Lines بروید


برای شخصی‌سازی ظاهر قالب، به نمایش → شخصی‌سازی بروید

رنگ‌ها، موقعیت تایم‌لاین و نوع منو را تنظیم کنید
تایم‌لاین
تایم‌لاین به طور خودکار در پایین یا بالای صفحه نمایش داده می‌شود. موقعیت آن را از بخش شخصی‌سازی تغییر دهید
